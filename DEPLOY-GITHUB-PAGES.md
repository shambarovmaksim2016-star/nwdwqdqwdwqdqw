# Публикация сайта для Ксюши через GitHub Pages

Этот комплект подготовлен для обычного статического сайта. Он не требует сборки или сервера.

## 1. Создать репозиторий
1. Откройте https://github.com/new и войдите в аккаунт.
2. Repository name: `for-ksyusha` (или любое своё имя).
3. Выберите **Public** и нажмите **Create repository**.

## 2. Загрузить файлы сайта
1. В репозитории нажмите **Add file → Upload files**.
2. Распакуйте архив и перетащите в окно загрузки четыре файла сайта: `index.html`, `styles.css`, `script.js`, `blue-roses-postcard.jpg`.
3. Нажмите **Commit changes**. Файл `index.html` должен лежать прямо в корне репозитория, а не во вложенной папке.

## 3. Включить GitHub Pages
1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. В качестве Branch выберите `main`, папку `/ (root)`, затем нажмите **Save**.
4. Подождите несколько минут и обновите Settings → Pages. GitHub покажет ссылку примерно такого вида: `https://ВАШ-ЛОГИН.github.io/for-ksyusha/`.
5. Сначала откройте ссылку на компьютере, затем проверьте на телефоне через Wi-Fi и мобильную сеть.

## Если ссылка не открывается на телефоне
Публикация на GitHub Pages уводит сайт с домена Cloudflare `workers.dev`, но доступность зависит от провайдера и региона; это не может быть гарантировано заранее. Если ошибка повторяется на телефоне в двух сетях, попробуйте открыть ссылку в другом браузере и отключить на время VPN, блокировщик контента или частный DNS. Сохраните точный текст ошибки.

## Что загружать
Нужны все четыре файла. Если не загрузить `styles.css`, исчезнет оформление; без `script.js` не будут работать интерактивные выборы; без `blue-roses-postcard.jpg` не откроется открытка.

## WhatsApp
Кнопка на сайте сформирует сообщение с выбранными ответами и откроет WhatsApp. Пользователь должен выбрать чат и нажать «Отправить» самостоятельно; сообщения автоматически не отправляются.
